13 — Life equation

The loop that survives motivation

VISION → TARGET → PLAN → SYSTEM → EXECUTION → MEASUREMENT → REVIEW → CORRECTION → REPEAT

Not: Motivation → Action → Failure → Restart. The system must work when motivation disappears.
