Legacy browser data migration

The previous static dashboard saved records in browser localStorage. The Django application cannot read that storage directly: open the old dashboard in the same browser, use its Export control to download the legacy JSON file, then import it here. Import creates database records and leaves the source backup unchanged. The older dashboard shipped with example goals, activity and scores when no local backup existed; inspect a legacy JSON file and remove any placeholders before importing.

Legacy seven-pillar scores are preserved as historical qualitative check-ins. They do not create the missing Family pillar history or imply measured outcomes.
