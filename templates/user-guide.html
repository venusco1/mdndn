User Guide

How to use MDNDN

A simple guide to setting up and using your personal Life OS.

Getting Started

MDNDN is a modular personal productivity system. You can start with just the basics and add more features as you need them.

What is MDNDN?

MDNDN helps you plan your long-term vision, organize daily work, track habits, and review progress in one private workspace.

Your first steps

  1. Sign in to access your private workspace
  2. Visit the Features page to see available modules
  3. Enable the modules you want to use
  4. Start with Vision and Today for a simple setup

Key pages

  • Today — Your daily command center for priorities, tasks, and habits
  • Dashboard — Overview of your system and progress
  • Features — Enable or disable modules
  • Settings — App preferences and data management

Understanding the Life OS

MDNDN uses a modular structure. Each component serves a specific purpose:

01

Vision

Your long-term direction, timeline, and major goals. Optional but recommended for planning.

02

Blocks

Time periods that break your vision into manageable phases. Requires Vision to be enabled.

03

Pillars

Life areas like health, career, relationships. Optional — use only what matters to you.

04

Goals & Targets

Measurable outcomes with progress tracking. Independent module.

05

Tasks

Specific actionable work with due dates and priorities. Independent module.

06

Habits

Recurring behaviors with daily check-ins. Independent module.

07

Reviews

Weekly, monthly, and block evaluations. Optional for reflection.

08

Journal

Daily reflections and notes. Independent module.

Setting Up Vision 30

Vision 30 is the long-term planning framework. You can configure it progressively:

You don't need to configure everything at once.

Start with a simple vision and add blocks, pillars, and goals as your needs evolve.

Basic setup

  1. Enable the Vision module from Features
  2. Set your vision name and timeline (up to 5 years)
  3. Define your start date and deadline

Adding blocks (optional)

  1. Enable the Blocks module
  2. Choose how many blocks you want (10, 20, or more)
  3. Configure each block's name, start date, and deadline

Adding pillars (optional)

  1. Enable the Pillars module
  2. Choose how many pillars you want (1-12)
  3. Configure each pillar's name and description
  4. Each pillar starts with one stage — add more later from the pillar detail page

Daily Workflow

A simple daily routine helps you stay focused and make progress:

Morning

Review Today

Open the Today page. Check your priorities and tasks for the day.

Midday

Execute

Work on your priorities, complete tasks, and track habits.

Evening

Reflect

Complete the evening reflection. Note wins and improvements.

Tip: Keep it simple. You don't need to use every feature every day. Focus on what matters most to you right now.

Managing Features

The Features page lets you control which modules are active in your workspace.

Enabling a module

  1. Go to Features from the sidebar
  2. Find the module you want to enable
  3. Click Enable
  4. The module will appear in your navigation

Disabling a module

  1. Go to Features
  2. Find the enabled module
  3. Click Disable
  4. The module will hide from navigation but your data is preserved
Important: Disabling does not delete data.

Your records remain in the database. Re-enabling the module restores access to all your data.

Module states

  • Disabled — Module is hidden but data is preserved
  • Empty — Module is enabled but has no records yet
  • In Use — Module is enabled and contains data

Frequently Asked Questions

How do I get started?

Sign in, go to Features, and enable Vision and Today. Set up your vision timeline, then start using the Today page for daily priorities.

Why is a module not visible in the sidebar?

The module may be disabled. Go to Features and enable it. If it's enabled but still not visible, check that you have the required dependencies (e.g., Blocks requires Vision).

How do I add a new goal or task?

Enable the Goals or Tasks module from Features. Then visit the respective page and use the create form to add your first item.

What happens when I disable a feature?

The module hides from navigation and widgets, but all your data remains in the database. Re-enabling the module restores full access to your records.

How do I change my settings?

Go to Settings from the sidebar. You can change vision dates, theme, timezone, and manage backups from there.

Is my data private?

Yes. Your records stay in the app's database. Export regular backups for safety. The application is designed for personal, private use.
