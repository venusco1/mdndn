A clear system for turning a life vision into daily action.

This guide explains what MDNDN Life OS is for, how its dashboard works, how to make a useful daily and weekly routine, and where your information is stored.

01 · PURPOSE

What problem does this project solve?

Long-term intentions are easy to forget when the day gets busy. This project puts personal direction, measurable goals, next actions, repeatable habits, and regular reflection in one place. It helps turn “I want to improve” into something that can be planned, done, and reviewed.

Direction

The home page is a reading space for identity, values, vision, life stages, and the age-30 deadline. It is not the place where you record daily work.

Execution

The dashboard is the working space: priorities, tasks, goals, habits, daily scores, journal entries, and an archive of milestones.

Review

Progress views make patterns easier to notice so you can adjust the plan instead of relying on memory or motivation alone.

This is a personal planning and reflection tool, not financial, medical, religious, or mental-health advice. Adapt the system to your own circumstances.

02 · FIRST SESSION

Start in five steps

  1. Read the home page. Start at index.html to understand the vision and the reasons behind the system.
  2. Open Overview. Go to the dashboard. It opens on Overview and shows your current snapshot.
  3. Make the Big 3 yours. Replace the example priorities with up to three outcomes that matter today, then save them.
  4. Use your own records. Create or edit goals, tasks, and habits. The initial dashboard includes sample records so you can see how each view works; replace or delete them as you personalize the app.
  5. Export a backup. After entering information you want to keep, use Export and store the downloaded JSON file somewhere safe.

03 · DASHBOARD REFERENCE

What each view is for

Overview

At-a-glance life metrics, your Big 3, the daily seven-pillar score, open tasks, and habits. Update priorities and log pillar scores here. A daily score is up to 14 points: choose 0 (not done), 1 (partial), or 2 (completed) for each pillar.

Goals

Create a goal with a title, category, pillar, target, optional unit and deadline. Enter a non-negative current value and a positive target. Use the progress field and Update button as your measure changes; Delete removes a goal.

Tasks

Add a next action, choose its priority and optional due date, then tick its checkbox when complete. The checkbox can mark a task complete or reopen it. Delete removes it.

Habits

Add a repeatable behavior, then mark it done for today. Marking it again removes today’s check-in. A streak is a run of consecutive calendar days; if you miss a day, the current run ends, while the best run remains.

Progress

Review the current score and averages across days with recorded scores. Pillar totals are based on the recorded score history. Updating a pillar score on Overview records or updates today’s entry.

Life

Read the fixed life vision, mission stages, and age-30 scorecard. Birth date and milestone dates are currently project settings, not editable profile fields.

Journal

Choose a mood and save a reflection. Entries are dated on the day you save them and shown newest first. Delete an entry to remove it.

Archive

Save achievements, reviews, milestones, and memories with a date and optional notes. This is a manually curated record; it does not automatically move completed tasks into the archive.

Global controls

  • Quick actions (+): choose a record type to open its dashboard view and focus the first input.
  • Theme: switch between light and dark. The selected theme is saved in this browser.
  • Read home / User guide: return to the vision page or this manual without losing saved entries.

04 · A PRACTICAL ROUTINE

Use the system without making it another burden

Morning · 3–5 minutes

Read the direction if needed. Choose a realistic Big 3, check the task list, and decide which habits you intend to complete.

During the day

Work from the task list. Mark a habit when it is done. Update goal progress when you have a meaningful new measurement—not just to keep the screen busy.

Evening · 5 minutes

Score each pillar honestly, write a brief journal entry if useful, and note one adjustment for tomorrow. A partial score is useful information, not a failure.

Weekly · 15 minutes

Review completed work, open tasks, goal movement, habit consistency, and journal notes. Keep what worked, remove stale commitments, and choose next week’s focus.

Keep your scores and goals honest. The dashboard is most useful as a feedback loop, not as a contest to reach a perfect score.

05 · YOUR DATA

Where information lives and how to protect it

  • Dashboard records are saved in this browser’s local storage on this device and for this site origin. They are not synced to an account or sent to a project database.
  • Another browser, device, or a different site address has a separate local copy. Use Export on the old browser and Import on the new one to transfer records.
  • Export downloads a JSON backup. The file contains your saved entries in readable form; keep it private and store it securely.
  • Import validates the backup and replaces the dashboard data currently stored in that browser. Export the current data first if you might need it. Cancel the confirmation to leave existing data unchanged.
  • Clear deletes the dashboard data in this browser. It cannot be undone; the app then returns to its built-in sample starting content.
  • Private browsing, clearing site data, browser storage limits, or browser policies may remove or prevent storage. Export regular backups for anything important.
Privacy reminder

This is not an encrypted vault or a login-protected account. Anyone with access to this browser profile may be able to view the dashboard and its local data. Avoid storing passwords, payment details, or information you would not want exposed.

06 · EXPECTATIONS

What this project does—and does not—do

MDNDN Life OS is a browser-based personal organizer. It provides manual tracking and review, with local backup and restore. There is no account or server-side database.

  • It does not send reminders, notifications, emails, calendar events, or recurring task alerts.
  • It does not sync between devices automatically or support multiple users and permissions.
  • It does not automatically calculate financial totals, verify goals, or move tasks into the archive.
  • Age and life-horizon metrics use the birth date and target dates configured in the app. Change the project settings/code if those dates are not appropriate for your use.
  • Example tasks, goals, scores, habits, and journal/archive records are starter examples—not real measurements. Review and replace them before using reports to make decisions.

07 · TROUBLESHOOTING

Common questions

My data is missing on another device. Where did it go?

Data is stored per browser and site origin, not in the cloud. Export from the original browser and import the JSON backup into the other one.

The dashboard did not keep my change.

Check that browser storage is enabled and that the browser is not in a restricted/private session. The app reports a save error if local storage rejects a change. Export important data regularly.

How do I undo Clear?

Clear cannot be undone from inside the app. If you previously exported a backup, use Import to restore it. Otherwise the removed local data cannot be recovered.

Why are there already records in the dashboard?

They are built-in sample records included to demonstrate how the views work. Delete or edit them as you set up your own workspace.

Does Import merge data?

No. Import replaces the saved dashboard state after confirmation. Export the current browser data first if you need to keep both copies.
